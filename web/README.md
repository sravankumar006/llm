# CommandLLM Web UI

This directory is the designated workspace for the frontend:
- **Framework**: React + Vite (TypeScript or JavaScript)
- **UI Paradigm**: Modern interactive terminal interface (retro-futuristic / sleek dark mode terminal, syntax highlighting, copy-to-clipboard, execution preview).

Initialization step:
```bash
cd web
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```
